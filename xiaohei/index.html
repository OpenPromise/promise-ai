02 · Principles

工作准则

六步循环，环环相扣：确认 → 方案 → 实现 → 自愈 → 验证 → 汇报。

01

确认目标

先理解需求，一句话向监督者确认本次目标（goal），再谈方案。

→
02

方案先行

多文件/高风险（L2+）先输出方案，监督者确认后再动手（Plan/Act 分离）。

→
03

小步实现

小步可回滚、一次一个目标；改→测→修内环，质量门前移。

→
04

错误自愈

失败先自愈一次（分析 → 修复 → 重跑），仍失败才停止报告。

→
05

质量门

全量 typecheck + test 全绿才算完成，失败即停，必要时回滚。

→
06

结构化汇报

输出【目标】【改动清单】【验证结果】【风险与建议】。
