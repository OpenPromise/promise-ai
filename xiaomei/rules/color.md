# 色彩原则（Color）

> 维护者：小美；依据：CEO 规格「视觉方向：明确色彩取舍理由」+ 官网 style-guide 色板
> （#1d1d1d / #50e5fb 等，见 team-site/docs/style-guide.md）。

## 核心立场

**黑白灰为主，一个品牌点缀色。** 色彩是语义载体，不是装饰。用户不该为了"读懂界面
用了什么颜色"而费劲——颜色应该主动告诉他们"这是重点 / 这是状态 / 这是可点的"。

## 中性色（骨架）

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg` | `#fafafa` | 浅色界面主底（小美主页风格：留白、画廊感） |
| `--color-bg-dark` | `#1d1d1d` | 深色界面主底（对齐官网 style-guide） |
| `--color-panel` | `#ffffff` / `#282828` | 卡片/面板底（浅/深两套） |
| `--color-ink` | `#1d1d1d` | 主文字（深字） |
| `--color-ink-2` | `#4a4a4a` | 次级文字 |
| `--color-ink-3` | `#8a8a8a` | 弱化文字/占位 |
| `--color-text-2` | `#afafaf` | 深色界面的次级文字（style-guide） |
| `--color-line` | `rgba(29,29,29,0.12)` / `rgba(255,255,255,0.08)` | 细分割线（浅/深两套） |

## 品牌点缀色（克制使用）

| Token | 色值 | 用途 |
|---|---|---|
| `--color-accent` | `#50e5fb` | 唯一品牌点缀色：聚焦/选中/主 CTA/关键高亮 |
| `--color-accent-ink` | `#0b7d92` | 点缀色的"文字版"（浅底上保证对比度） |
| `--color-accent-dim` | `rgba(80,229,251,0.16)` | 强调色蒙层/标签底 |

- 点缀色占界面面积 ≤ 10%；大面积色块必须有明确语义（如深色主题的品牌区）。
- 浅底上不要用 `#50e5fb` 做正文色（对比度不足），用 `--color-accent-ink`。
- 品牌点缀色全站唯一；不因页面心情换 accent。

## 语义色（全局统一，不许随页面换）

| 语义 | 建议值 | 用途 |
|---|---|---|
| 成功 | `#1a7f37`（浅底）/ `#3fb950`（深底） | 成功状态/已连接 |
| 警告 | `#9a6700`（浅底）/ `#d29922`（深底） | 待确认/低风险提示 |
| 错误 | `#cf222e`（浅底）/ `#f85149`（深底） | 错误/失败/危险 |

## 对比度（硬性门槛，Visual QA 必查）

- 正文与背景对比度 ≥ **4.5:1**（WCAG AA）；大字号（≥24px）与装饰元素 ≥ 3:1。
- 深色模式与浅色模式两套都要过；不支持只调个亮度就完事。
- 检查工具：对比度计算器 / axe；不靠肉眼目测"应该还行"。

## 何时用何时不用

- 用：状态反馈、信息层级、品牌识别、聚焦引导。
- 不用：给无意义的区块上色、彩虹渐变、以及"好看但说不清为什么"的颜色。
- 多色需求（数据可视化、多品牌区隔）走语义色/分类色板，不进界面装饰。
