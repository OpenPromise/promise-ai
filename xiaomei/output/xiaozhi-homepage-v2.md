## 0. 一句话目标

把小知主页从「暖棕档案名片」升级为「深夜情报档案室」——打开就像翻开「情报卷宗 XZ-000」：左上角编号与日期、结论先行的小卡片、每条结论底下跟着来源脚注、一枚琥珀色印章。让陌生访客 **10 秒**知道这是谁、**30 秒**找到她最近在研究什么、**60 秒**相信她每条结论都有出处。

## 1. UX 分析

- **用户是谁**：① CEO（10 秒知道小知是谁、凭什么信她）② 小夜姐（监督与验收）③ 小黑（协作边界与开发依据）④ 新同事（研究找谁报、什么移交谁）
- **核心任务**：回答三个问题——小知是什么人、她最近在研究什么、她凭什么可信。
- **最常用功能**：首屏判断身份 → 证据链感受"结论+来源"的可信示范 → 简报墙找到真实成果入口。
- **信息常驻/隐藏**：身份/信条/近期主题常驻首屏；工作方式/边界/证据链/简报墙随滚动；锚点导航保证 60 秒内可达任何区块。
- **完成核心任务步骤**：首屏 1 眼（名字+职务+定位+印章+近期主题）→ 滚动 3 屏（工作方式+边界+证据链）→ 1 次点击（简报墙真实入口）。全程 ≤60 秒。

## 2. 设计概念：「深夜情报档案室 / 情报卷宗 XZ-000」

小知本人的比喻就是设计语言，三层叠在一起：
1. **一份写给我的入职简报**——结论先行、带来源、带置信度、落款在底，页面本身就是她工作方式的样本；
2. **深夜书房里灯下摊开的资料台**——暖琥珀光、散着便签和卡片，安静但亮着；
3. **一张编好索引的知识卡片**——mono 编号、路径、时间戳，一切有出处。

落实成具体视觉：

| 比喻元素 | 设计落点 |
|---|---|
| 卷宗封面 | Hero 右侧「卷宗卡」：编号 XZ-000 + 建档日期 + 琥珀印章「已查证」 |
| 档案编号 | 全页编号标签 XZ-00X / D-0X / N1-N3，mono 琥珀 |
| 结论先行 | 工作方式 4 步管线 + 证据链卡片，每张"结论 → 来源"上下结构 |
| 来源脚注 | 证据链节点/示例条目下方 mono 小字：判例号/机构/文件名 |
| 琥珀印章 | 唯一强调元素：Creed 引用块 + 卷宗卡 + footer 落款各一枚（克制） |
| 知识图谱 | 「证据链」区块：三个真实主题（AIGC 版权 / 开源协议 / 模型选型）用小连线串起 |

**关键设计决策**：印章「已查证」的语义=「本页内容均有出处（全部来自小知本人文档与本人回复）」——不是"她的研究成果全部正确"。此语义写入代码注释，防止被误读为造假（小知红线：无来源断言 = FAIL）。

## 3. 视觉方向

**风格关键词**：深夜档案室 / 情报卷宗 / 结论先行 / 安静可信 / 书卷气 / 克制。像档案柜深处 + 一张批注整齐的文献综述。

### 色彩（琥珀 = 灯下读到的光 = 可靠的结论；灰 = 还没查证）
- 深墨蓝近黑底 `#0d1017`（档案柜深处，从 v1 暖棕 #1a1208 升级——小知本人回复明确要"深墨蓝/近黑"）
- 面板 `#141b26`、描边 `rgba(250,204,21,.16)`、hover 亮边 `rgba(250,204,21,.32)`
- **琥珀金 `#facc15` = 唯一强调色**：印章、编号标签、关键结论、可点、高置信度。面积 ≤10%。
- 米白 `#f4e7c5`（正文/纸张）、次级 `#b39b6a`（弱化棕金）
- 待验证/进行中 `#8a8066` 虚线灰（语义=还没查证，只用标签/图形/虚线，不做正文）
- DONT 语义用灰（弱化），DO 用琥珀（强调"我做"的事）——不引入红色，守住"琥珀唯一强调"

### 字体
- 标题衬线（Songti SC / Noto Serif SC / Source Han Serif SC）——书卷气，像档案标题
- 正文无衬线（PingFang SC / Microsoft YaHei / Noto Sans SC）
- mono（ui-monospace / JetBrains Mono / Cascadia Code / Consolas）——编号、来源、置信度、时间戳、路径
- 单界面 3 家族是她的 self-brief 明确要求（衬线标题+无衬线正文+mono 标注），团队 typography 规则允许品牌级 Hero 用衬线

### 间距 / 圆角 / 阴影
- 4px 基准网格；容器 ≤860px；卡片 padding 20-24px；列表行 ≥44px；区块间距 ≥64px
- 圆角：卡片 10px、徽章 6px、印章圆角 6px（或圆形）——克制，不用大圆角
- 阴影：默认无；hover 不浮重影，只「边框亮起 + 上移 2px」

### 氛围背景
- 极淡琥珀网格（32px，透明度 0.04，CSS linear-gradient）+ 右上角一束琥珀微光（radial-gradient 6%）。零图片、零依赖、静态。

### 动效（极克制）
- reveal 滚动淡入一次（团队共同语言）；hover 描边/文字变色；无粒子、无轮播、无弹跳、无自动播放、无加载动画；全部 `prefers-reduced-motion` 降级。印章静止不闪。

## 5. 升级点 vs 克制底线

**升级点（出彩但不越界）**：
1. **卷宗卡 + 琥珀印章**——全页视觉记忆点，把"档案感"压进首屏
2. **证据链（知识图谱）**——三个真实主题 CSS 连线，零依赖，示范"结论+来源"样式
3. **示例简报条目**——真实证据感：结论 + 判例来源脚注并排（注释声明示意，案号待小知核实）
4. **工作方式管线**——QUESTION/EVIDENCE/ANSWER/ARCHIVE 4 步，CEO 一眼看懂她的方法论
5. **置信度三态**——已查证（琥珀实心）/ 待验证（虚线灰）/ 未查到（灰），全页统一
6. **DONT 灰 / DO 琥珀**——不引入红色，守住"琥珀唯一强调"的语义体系

**禁区（小知红线，设计上就规避，SPEC 里写死）**：
- ❌ 无来源的断言与自夸形容词（"权威""顶尖""第一"）——出现即 FAIL
- ❌ 假数据、编造的"已读文献数/调研场次"、假简报条目
- ❌ 把推断写成事实；没有置信度标注的结论
- ❌ 炫技动效（粒子/视差/轮播/弹窗/无限滚动/加载动画）
- ❌ 大段调研正文（主页只放入口，那是知识库的活）
- ❌ 琥珀色超过唯一强调（面积 >10%）、待验证不用虚线灰
- ❌ 不引入任何红/绿/蓝等其他语义色（区别于小真的绿、小黑的青）
