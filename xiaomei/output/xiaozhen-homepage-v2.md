## 0. 一句话目标

把主页从「文字堆叠的简朴名片」升级为「一张会呼吸的验收单」——延续深灰绿 QA 人设不跑偏，让陌生访客 **10 秒**读出「这是谁、负责什么、能不能信」，**30 秒**找到「缺陷找谁报、什么移交谁」。

## 1. UX 分析

- **用户是谁**：① CEO（10 秒判断这个人可不可信）② 小黑（找协作边界与移交对象）③ 新同事（想知道缺陷找谁报）
- **核心任务**：回答三个问题——小真是什么人、凭什么可信、问题移交谁。
- **最常用功能**：看首屏判断身份 → 看证据墙验证可信 → 找移交表定位责任人。
- **信息常驻/隐藏**：身份/信条常驻首屏；职责/边界/证据随滚动出现；锚点导航保证 30 秒可达任何区块。
- **完成核心任务步骤**：首屏 1 眼（名字+职务+状态卡）→ 滚动 2 屏（职责+边界+移交表）→ 1 次点击（证据链接）。全程 ≤30 秒。

## 2. 设计概念：「验收单 / 测试报告第一页」

小真自己的比喻就是设计语言：**一张贴在服务器机房门口的验收单**、**测试报告的第一页**——结论先行，证据在后，落款在底。本方案把这两个比喻落实成具体视觉：

| 比喻元素 | 设计落点 |
|---|---|
| 验收单抬头 | Header 字标 `XIAOZHEN / QA` + 状态灯 |
| 报告首页结论区 | Hero 区「QA GATE 状态卡」：大绿勾 STATUS: PASS + OWNER/ROLE/LAST RUN/SIGNAL |
| 主结论（一句话） | Creed 信条：全页唯一宣言，签章式引用块 |
| 检查单 | 职责 4 卡（D-01..04 编号）、边界 DO/DONT ✓✗ 清单 |
| 移交路径 | 移交表（问题类型 → 成员链接，mono 成员 ID） |
| 证据附件 | 证据墙：编号/结论/摘要/时间戳 检查单条目 |
| 落款签章 | Footer 签名 + PASSED 日期章（语义=本页自检通过） |

**关键设计决策**：状态卡的 `PASS` 不是「小真工作全部通过」的假数据，而是「本页自检通过」——页面真实包含 身份/职责/边界/证据/移交 全部要素，因此 PASS 有可验证依据。这一语义必须在代码注释中写死，防止被误读为造假（小真红线：假绿勾 = FAIL）。

## 3. 视觉方向

**风格关键词**：验收单 / 测试报告第一页 / 冷静 / 证据感 / 工科 / 克制。像测试控制台 + 一张写满批注的检查单。

### 色彩（语义即颜色，非装饰）
- 深灰绿底 `#07140f`、面板 `#0c1c16`、描边 `rgba(74,222,128,.16)` —— 灰绿阶为基座
- 翠绿 `#4ade80` = PASS / 可点 / 重点，面积克制（状态、徽章、hover、编号）
- 玫红 `#fb7185` = 仅真实 FAIL 与 DONT 标注，绝不装饰用
- 正文 `#e8f5ec`、次级 `#8aa896`
- 新增 1 个 token：`--line-strong rgba(74,222,128,.32)`（hover 亮边）。其余沿用小真现有 token，不造 token 通胀。

### 字体
- 正文：`PingFang SC / Microsoft YaHei / Noto Sans SC / system-ui`（无衬线——「我不是杂志，我是工科」）
- 等宽 mono：编号、路径、时间戳、状态、签章——「一切结论都有命令行出处」
- 单界面 2 个家族（团队 typography 规则），不用衬线。

### 间距 / 圆角 / 阴影
- 4px 基准网格；容器 ≤860px；卡片 padding 24px；列表行高 ≥44px；区块间距 ≥64px
- 圆角小半径：卡片 12px、徽章 6px、状态卡 12px —— 工科感，不用大圆角
- 阴影：默认无；hover 不浮重影，只「边框亮起 + 上移 2px」——面板靠描边与间距区分，不靠阴影

### 氛围背景
- 极淡灰绿网格（32px，透明度 0.04，CSS linear-gradient 绘制）+ 右上角一束翠绿微光（径向渐变 6% 透明度）。零图片、零依赖、零动效、静态。

### 动效（极克制）
- reveal 滚动淡入一次（现有保留）；hover 描边/文字变色；状态卡绿勾极轻脉冲（scale 1→1.03, 2.4s 循环）；全部 `prefers-reduced-motion` 降级。无轮播、无弹跳、无粒子、无加载动画。

| # | 区块 | 内容 | 验收理由 | 设计落点 |
|---|---|---|---|---|
| 1 | Header | `XIAOZHEN / QA` 字标 + 锚点导航（信条/职责/边界/证据墙/梦想）+ 返回官网 `../` | 10 秒定位入口，不能迷路 | sticky 顶栏 + 绿点状态灯 |
| 2 | Hero | 名字 + 职务 + 一句话定位 + **QA GATE 状态卡** | 第一屏必须答「我是谁」 | 左文右卡，10 秒信息密度 |

| 4 | 职责 | 4 张卡：独立验收 / 证据优先 / 只报不修 / 绿灯值钱 | 答「我干什么」 | D-01..04 编号 + 左侧 2px 绿条 |
| 5 | 边界 | 「我不做什么」清单 + 移交表（实现→小黑 / 环境→小优 / 设计→小美 / 派单→小夜姐） | 答「我凭什么可信」 | ✓✗ 检查单 + 移交表 |

| 7 | 梦想 + Footer | 一句话梦想 + 工位/入职/汇报/入口 + 签名 + PASSED 章 | 人味收尾，诚实落款 | 落款签章 |

## 5. 升级点 vs 克制底线

**升级点（出彩但不越界）**：
1. **Hero 状态卡**——全页视觉记忆点，把「我是谁/负责什么/可不可信」压进一张卡
2. **网格背景 + 微光**——测试控制台氛围，CSS 绘制零依赖零成本
3. **检查单式边界**——✓/✗ 符号列，红绿只出现在语义位置
4. **证据墙条目化**——编号/结论/摘要/时间戳，像缺陷条目
5. **落款签章**——PASSED 日期章，验收单收尾
6. **hover 亮边 + 2px 上移**——状态反馈，不是表演

**禁区（小真红线，设计上就规避，SPEC 里写死）**：
- ❌ 无自夸形容词（「业界顶尖」「100% 可靠」）——出现即 FAIL
- ❌ 无假数据、无编造验收记录、无假绿勾（PASS 语义只能是「本页自检」，代码注释写死）
- ❌ 不把 FAIL 粉饰成「优化建议」
- ❌ 无弹窗 / 轮播 / 无限滚动 / 加载动画 / 粒子 / emoji 图标
- ❌ 红叉只用于缺陷/DONT 标注；红绿不参与装饰
- ❌ 不改变色语义、不加渐变彩虹

## 7. 验收对照（对着小真的标准逐条自检）

**主验收标准（self-brief 第二部分 0 节）**：
- ✅ 10 秒说出「这是谁/负责什么/能不能信」：Hero 首屏=名字大字+职务+状态卡（PASS+OWNER+ROLE+SIGNAL），Creed 紧随首屏可见
- ✅ 30 秒找到「缺陷找谁报/什么移交谁」：Header 锚点「边界」直达移交表，4 行成员链接可点击

**小真附赠验收清单（self-brief 附）**：
1. ✅ 首屏 3 秒出现名字/职务/信条——Hero 紧凑 + Creed 紧跟，控制在首屏内
2. ✅ 证据墙链接真实可点——唯一真实链接 `./self-brief.md`（已核实存在），不放空链
3. ✅ 全页无自夸形容词、无假数据——文案逐字沿用她的原话
4. ✅ 深色底 + 语义色克制，红叉只用于缺陷标注
5. ✅ 所有动效有 prefers-reduced-motion 降级
6. ✅ 移动端单列可读、锚点可达（响应式见 SPEC）
