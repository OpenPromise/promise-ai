# 参考品牌分析：Vercel

> 记录：小美；用途：吸收设计思想，不复制视觉外壳。每次引用前先想"这里适不适用"。

## 为什么这样设计

Vercel（前端部署平台）的设计语言是**工程美学**：黑白极简 + 几何秩序，让"部署、
环境、日志"这类抽象概念显得具体可信：

- **黑白极简**：页面几乎只有黑白灰；可读性靠对比度与间距，不靠颜色。
- **几何秩序**：网格严谨、对齐精确、圆角统一（小圆角），整体像"用工具画出来的"，
  呼应其开发者受众的审美。
- **信息架构清晰**：仪表盘侧边栏 + 内容区层级分明；环境、域名、日志各自成区，
  用户永远知道"我在哪个系统里"。
- **状态可视化**：构建/部署状态用统一图标 + 状态色 + 时间线，一瞥即知"到哪一步"。
- **字体即品牌**：用自家字体与等宽元素强化工程感，代码块、路径、命令都等宽呈现。

## 解决什么问题

- **抽象概念的具象化**：部署、Serverless、边缘网络看不见摸不着，黑白极简 +
  清晰架构让用户"感觉自己在控制台里操作真实的东西"。
- **可信度**：对开发者来说，"干净利落"本身就是专业性的证明——没心思装饰的
  工具才靠谱。
- **长时间使用**：低饱和、低对比冲击的界面，写代码/盯构建一整天不累眼。

## 何时用 / 何时不用

**适用**：开发者工具、控制台/仪表盘、任何"用户在认真干活"的场景。

**不适用**：
- 面向普通消费者的产品：黑白极简对非技术用户可能显得"冷、没有温度"。
- 需要强品牌记忆的营销页：全黑白会让品牌个性消失（Vercel 的营销页其实也会
  用几何图形与动效撑记忆点）。
- 需要情感引导的场景（新手引导、健康类 App）：需要更温和的色彩与语气。

**借用要点**：几何秩序、状态可视化、"工具感"三件套适合一切工程向界面；
但黑白极简要配"足够好的层级与间距"，否则会退化成"简陋"而非"高级"。
