## 2. 整体视觉风格

- **基调**：深色、高对比、图片/视频驱动。全站近乎"黑底 + 内容图"，UI 控件以半透明/深色块呈现，让大图成为视觉主角。
- **质感**：都市霓虹感（《异环》超自然都市题材），冷色光为主，辅以少量暖粉点缀。
- **沉浸式**：无传统内容滚动页，全部内容在全屏"翻页"容器中（Swiper 全屏 slide），符合游戏官网"场景化叙事"惯例。

## 4. 布局结构（DOM 骨架证据）

```
┌ loading 加载页（#1d1d1d，波浪文字动画）──────────┐
├ header（固定顶栏）──────────────────────────────┤
│   logo(左) │ headerNav 导航(中) │ 登录(右，已去掉) │
├ 全屏 Swiper 翻页容器 ───────────────────────────┤
│ ① pageIndex  首页：全屏背景视频 + 下载按钮组 + 平台入口 + 底部悬浮 footer │
│ ② pageNews   情报速递：标题 + 4 个 Tab（公告/新闻/广播/活动）+ 列表 + 轮播 │
│ ③ pageRole   角色介绍：左侧竖排角色导航(图) + 每角色一屏(背景视频+立绘名+简介+正文) │
│ ④ pageView   世界全景：标题 + 板块切换按钮 + 缩略导航 + 多板块轮播(场景图+标题+描述) │
│ ⑤ pageCity   都市映像：全屏场景轮播 + 标题 + 分页 │
├ footer（悬浮于首页底部：平台入口 + 客服 + 适龄标识）┤
└ 弹窗：视频播放 pop / 登录 pop（登录已去掉）───────┘
```

关键布局手法（CSS 证据）：

- **全屏绝对定位**：各板块内容大量使用 `position:absolute` + 百分比定位（如 `.roleNav{left:1.2rem;top:50%;transform:translateY(-50%)}`），rem 基准适配不同屏幕。
- **顶栏**：`header` 固定；导航/登录为绝对定位浮动块。
- **竖排角色导航**：`.roleNav` 为左侧窄竖条（width:1.69rem），内部再套横向 Swiper 做角色 tab。
- **标题全部为切好的图片**（如 `.pageViewTit`、`.newsHead` 都是背景图），文字标题做在图里——这对我们是个可复用的风格线索，但落地时建议用 CSS 文字标题（可维护、可 SEO），风格上用同样排版位置模拟。

## 5. 字体风格

- 唯一显式声明：`font-family:"Microsoft YaHei",Arial,sans-serif`（public.css）。
- 正文层级靠字号/字重/颜色区分，无衬线、无手写体。
- 落地建议：中文字体栈用 `"Microsoft YaHei","PingFang SC","Noto Sans SC",sans-serif` 系统回退（避免字体文件打包与授权问题），数字/代码用等宽栈（团队官网含工程元素，可适度加入 mono 点缀）。

## 6. 动效特征（代码证据）

- **视频背景**：首页全屏 `<video autoplay muted loop>`（`yh_bgvideo_20260418.mp4` + poster 封面）——品牌首屏核心动效。
- **角色背景视频**：每个角色 slide 内各有独立 `roleBg` 视频（同一静态资源模式）。
- **全屏翻页**：Swiper 整屏滑动切换（`swiper-bundle.min.js`），支持 `?nav=N` 直达页码。
- **加载动画**：加载页三列波浪文字（`animation:textWavy 1.5s ease-in-out infinite`），素材预载完成后淡出。
- **hover 态**：按钮/新闻条目有 hover 提亮（`#4fe5fb` 系高亮），新闻列表为"图片列表 + 标题"。
- 无滚动视差/无 JS 粒子（粒子类效果未见；星空粒子是小黑主页自有的，不是参考站特征）。

## 8. 新闻数据结构（真实样本，供 content-model 参考）
